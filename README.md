# [Portfolio] Advanced Bow Action & Combo System
**UE5.7 기반의 데이터 주도형 활 전투 시스템 및 몬스터 헌터 스타일 콤보 프레임워크**

본 프로젝트는 활(Bow)을 활용한 정밀한 조준 사격 매커니즘과 물리 기반 화살 투사체 시스템, 그리고 상태 기반의 복잡한 액션 콤보를 구현한 기술 데모입니다. Actor Component를 활용해 로직을 모듈화하고, UPrimaryDataAsset을 통해 확장성 있는 데이터 구조를 설계했습니다.

---

## 🛠 주요 기술 역량 (Technical Highlights)

### 1. 모듈형 전투 컴포넌트 (AC_BowMechanics)
- **Decoupled Logic:** 캐릭터 본체와 전투 로직을 분리하기 위해 Actor Component를 사용하여 활 전용 상태 및 입력을 관리합니다.
- **Mesh Attachment:** 소켓 시스템을 활용해 캐릭터 메시와 활(Bow) 메시를 동적으로 장착/해제하는 로직을 구현했습니다.

### 2. 정밀 조준 및 카메라 시스템
- **Adaptive Camera:** 조준 입력 시 시야각(FOV)과 카메라 오프셋을 조정하여 몰입감 있는 사격 환경을 조성했습니다.
- **Character Rotation:** 조준 시 캐릭터 메시가 카메라의 전방 방향을 동적으로 추적하도록 회전 로직을 수정했습니다.
- **Crosshair Widget:** 조준 상태에 따라 반응하는 UI 위젯을 제작하여 사용자 경험을 개선했습니다.

### 3. 물리 기반 화살 투사체 및 탄도학
- **Trajectory Calculation:** 화살의 중력과 속도를 고려한 투사체 경로 계산으로 현실적인 발사 궤적을 구현했습니다.
- **Impact System:** 화살이 벽이나 구조물 등 물리적 표면에 박히는 로직을 구현했으며, 타격 시 데미지 전달 시스템을 연동했습니다.
- **SFX/VFX:** 화살 장전, 발사 시 사운드 이펙트를 적용하여 타격감을 극대화했습니다.

### 4. 몬헌 와일즈 스타일 콤보 및 챠지 시스템
- **Variable Power Shot:** 활을 당기는 시간에 비례하여 '조준 강도'가 증가하며, 강도에 따라 발사 속도와 데미지가 차등 적용되는 시스템을 구현했습니다.
- **Action Combo Framework:** 몬스터 헌터 와일즈의 흐름을 벤치마킹하여, 특정 애니메이션 프레임에서 다음 액션으로 연계되는 콤보 시스템을 구축했습니다.
- **Animation State Machine:** 캐릭터의 조준, 장전, 발사로 이어지는 일련의 동작을 Animation Blueprint 내에서 유기적으로 연결했습니다.

## 📂 구현 세부 사항

### ⚔️ 전투 시스템 (Combat)
- **Charging Mechanics:** 챠지 단계별 애니메이션 및 이펙트 변화.
- **Arrow Spawning:** 발사 시점에 맞춘 투사체 스폰 및 초기 벡터 할당.
- **Damage Interface:** 인터페이스를 활용해 피격 대상의 타입에 관계없이 데미지를 전달하는 구조.

### 🏃 애니메이션 (Animation)
- **Aim Offset:** 조준 각도에 따라 상체가 자연스럽게 움직이는 에임 오프셋 적용.
- **Montage & Notify:** 애니메이션 몽타주와 노티파이를 활용해 화살 스폰 타이밍 및 사운드 재생 시점 정밀 제어.

## 🚀 문제 해결 경험 (Troubleshooting)

### [Issue] 조준 강도에 따른 화살 궤적의 가변성
- **Problem:** 화살을 약하게 쏠 때와 강하게 쏠 때의 궤적 차이가 직관적이지 않음.
- **Solution:** 챠지 단계에 따라 InitialSpeed와 중력 계수를 동적으로 조절하는 물리 방정식을 적용하여, 강하게 쏠수록 탄속이 빠르고 낙차가 적은 직관적인 탄도학을 완성했습니다.

### [Issue] 콤보 연계 시 애니메이션 끊김 현상
- **Problem:** 몬헌 스타일의 선입력 및 연계 동작 시 상태 전환이 매끄럽지 않음.
- **Solution:** AbilitySystemComponent(GAS)의 태그 시스템을 활용하거나, 커스텀 AnimNotifyState를 통해 콤보 유효 프레임을 정의하여 부드러운 상태 전이를 구현했습니다.
